# PetWorld - Платформа для пошуку улюбленців
веб-додаток, створений для практики UI-тестування та автоматизації. 

## Технології
* **HTML5** 
* **Tailwind CSS** (через CDN) для швидкого та адаптивного дизайну
* **JavaScript** для інтерактивних елементів (галерея)

## Мета проєкту
Проєкт імітує реальну платформу оголошень з:
* Динамічними формами та випадаючими списками
* сітками (CSS Grid / Flexbox)
* Клікабельними картками та галереями зображень

## 🚀 Розгортання (Docker)
проєкт підготовлений для швидкого розгортання у Linux-середовищі за допомогою контейнеризації (використовується оптимізований образ вебсервера `nginx:alpine`).
**Команди для локального запуску:**
```bash
# 1. Зібрати Docker-образ:
docker build -t petworld-app .
# 2. Запустити контейнер у фоновому режимі (порт 8080):
docker run -d -p 8080:80 petworld-app
